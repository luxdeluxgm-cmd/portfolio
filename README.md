# Jan Tokarzewski – Personal Portfolio

A custom-coded and lightweight personal website and service portal. Built for simplicity without heavy frameworks or bloated CMS templates.

## Tech Stack
* **HTML5**
* **Tailwind CSS** (via CDN)
* **Vanilla JavaScript** 

## Local Development
No build tools required. Open any `.html` file in your browser to view the layout. To fully test the clipboard API and Formspree contact form, serve the directory locally:
```bash
python3 -m http.server
```
Then navigate to http://localhost:8000.
